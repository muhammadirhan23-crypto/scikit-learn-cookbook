# scikit-learn Cookbook — Third Edition

## About This Repository

This repository contains code reproductions, theoretical explanations, and chapter summaries based on *scikit-learn Cookbook, Third Edition* by John Sukup.

This project is part of the individual assignment for the Enrichment for Machine Learning Classes.

## Chapter Overview

- **Chapter 1:** Common Conventions and API Elements of scikit-learn
- **Chapter 2:** Pre-Model Workflow and Data Preprocessing
- **Chapter 3:** Dimensionality Reduction Techniques
- **Chapter 4:** Building Models with Distance Metrics and Nearest Neighbors
- **Chapter 5:** Linear Models and Regularization
